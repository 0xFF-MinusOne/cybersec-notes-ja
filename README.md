# サイバーセキュリティノート

私のブログへようこそ! 内容が多く、少し散らばっているので、案内を書いておきます。

* バイナリエクスプロイトのノートを探しているなら、ここで正解です! ここには、私が学んだことのほとんどについてのノートがあり、自分で試せるように脆弱なバイナリも提供しています。「定番」のスタックの手法はほとんど取り上げており、ごく入門的なヒープも少しあります。今後さらに追加します(more will come soon™)。
* リバースエンジニアリング、暗号、ブロックチェーンのセキュリティに関するノートや、writeup もいくつかあります
* 暗号以外の数学のノートは、すべて Notion の[こちら](https://ir0nstone.notion.site/Maths-3bb97c269fdc4dde810a3bb3ef9780f1?pvs=4)にあります。複数の場所にあるのが面倒なのは承知していますが、Notion の数式のサポートがとにかくずっと優れているのです。_本当に_ 段違いです。ごめんなさい。
