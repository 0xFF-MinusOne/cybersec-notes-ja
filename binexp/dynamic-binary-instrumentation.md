# Dynamic Binary Instrumentation

## 概要

**動的バイナリ計装(Dynamic Binary Instrumentation、DBI)**は、ソースコードがなくても、実行中のプログラムを観察、解析、改変できる手法です。

あまり役に立たなそうに聞こえるかもしれませんが、実際にはとても便利です。代表的な例は**ファジング(fuzzing)**です。非常に複雑なコードベースを持つ大きなバイナリでは、ファジングが最良の手段になることがあります。ただ、AFL++ のようなファザーは、バイナリが専用の方法でコンパイルされていることを前提にするのが普通です。ファザーを効率よく動かすには、どのコードパスを通ったか、どこでクラッシュしたかを追跡したいからです。そのために、コードの実行がある地点に到達すると「メッセージ」を出す、ファザー用の「フラグ」をバイナリにたくさん埋め込んでコンパイルします。これでファザーはどのバグを見つけたかを正確に把握できます。ただし、これができるのはソースコードがある場合だけです。

そこで DBI の出番です。ソースコードがなくても、追加の命令を**注入(inject)**して、メモリアクセスの記録、制御フローの追跡、命令数の計測などができます。これにより、実際に**何が**実行されているかを把握できます。その代わり、当然ながら性能は落ちます。

代表的なフレームワークには、非常に強力な [Frida](https://frida.re) と、定番の [Valgrind](https://valgrind.org/info/) があります。Valgrind は、メモリリークやメモリ破壊を見つけるときに、多くのプロジェクトがまず使うツールです。
