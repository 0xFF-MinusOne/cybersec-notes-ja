# Heap

ヒープ(heap)のエクスプロイトに進むのに、スタックのエクスプロイトの達人である必要は**ありません**。ただし、C 言語と、ポインタ(pointer)のような概念の仕組みについて、より深い理解が必要になります。ときどき glibc のソースコードそのものを扱います。圧倒されそうになることもありますが、とても良い訓練になります。

できるだけ分かりやすくなるよう努めます。最初のうちは、参照先の多くをハイパーリンクにしています。今のところは概念だけ頭に置いておけば十分です。ただ、学習が進むにつれて、ソースを理解することがどんどん重要になっていきます。

{% hint style="info" %}
コードの断片は、glibc のバージョンがそれぞれ異なるものから引用していることがあります。どのバージョンのものかは、できるだけ書いておきます。新しいバージョンには多くの保護機構があり、処理の基本的なロジックが見えにくくなるためです。そこで、まず古い実装から始めて、段階的に積み上げていきます。
{% endhint %}
